# Support

Labyrithm is a beta self-hosted platform. Support is currently community- and maintainer-led.

## Before Asking for Help

1. Read the [README](README.md) and [quick-start guide](docs/quick-start.md).
2. Check the [deployment guide](docs/deployment.md) and [monitoring guide](docs/monitoring.md) for operational issues.
3. Search existing GitHub issues.
4. Remove credentials, tokens, personal data, and private contest information from logs.

## Bug Reports

Open a bug report with the affected version or commit, deployment mode, operating system, reproduction steps, expected behavior, actual behavior, and relevant sanitized logs.

## Questions and Feedback

Use a GitHub discussion or issue for general questions, design feedback, and feature proposals. Use the private process in [SECURITY.md](SECURITY.md) for vulnerabilities.

For contest operators, include whether the issue affects the API, frontend, worker, database, desktop agent, or deployment environment.
