You are given an array of $N$ integers $a_1, a_2, \ldots, a_N$.

Answer $Q$ queries. Each query gives two indices $l$ and $r$ ($1 \le l \le r \le N$) and asks for the sum of the subarray:

$$\sum_{i=l}^{r} a_i$$

### Input

- The first line contains two integers $N$ and $Q$.
- The second line contains $N$ integers $a_1 \ldots a_N$.
- Each of the next $Q$ lines contains two integers $l$ and $r$.

### Output

For each query, print the sum on its own line.
